# Data Handling Kickoff Checklist

Complete this checklist jointly once before project work begins. It is a shared control for the MSBA student team and Dana's team; it is not a per-task checklist.

**Project:** __________  
**Date:** __________  
**Student team lead:** __________  
**Dana's designated owner:** __________

## 1. Scope and permitted use

- [ ] We identified the project files, datasets, analysis outputs, contact details, and meeting communications involved.
- [ ] We confirmed the work is not expected to include personal, confidential, or regulated data.
- [ ] We will use project data only for the agreed MSBA capstone work.
- [ ] If new sensitive, confidential, or personal data enters scope, we will pause and obtain guidance from both leads before using it.

## 2. Storage and access

- [ ] All project data will be stored and shared only through Dana's organization-approved tools.
- [ ] Access is limited to named project members.
- [ ] Dana's team has approved access for each named member.
- [ ] We will not copy project data into personal storage, unapproved applications, or external tools.

## 3. Sharing

- [ ] We will share data or project outputs outside the named project team only after approval from both leads.
- [ ] We will use only approved sharing methods.
- [ ] We will not use project data in portfolios, presentations, publications, or other work unless both leads approve it.

## 4. Policy alignment

- [ ] We reviewed the applicable university and Dana's organization data-handling policies.
- [ ] Where those policies differ, we will follow the stricter requirement.
- [ ] Both leads know where the applicable policies and approved workspace are located.

## 5. Incident response

- [ ] If data is misdirected, exposed, lost, or accessed unexpectedly, we will promptly notify both the student-team lead and Dana's designated owner.
- [ ] We will preserve relevant details so the incident can be assessed and addressed under Dana's organization procedures.

## 6. Project closeout

- [ ] At capstone completion, both leads will decide what is retained, transferred, or deleted.
- [ ] Student team members will follow that documented closeout decision.
